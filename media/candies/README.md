# הפרסים

התמונות כאן הן מה שהילדות מגלות מאחורי הלוח. המשחק מגריל אחת מהן לכל לוח חדש.

## להוסיף ממתק

**1.** שים קובץ תמונה בתיקייה הזו — שם באנגלית, אותיות קטנות, מקפים:
`bamba.jpg`, `krembo.jpg`, `chocolate-milk.jpg`

**2.** פתח את `index.html`, חפש `const CANDIES`, והוסף שורה:

```js
{ name: "במבה", icon: "🥜", img: "media/candies/bamba.jpg" },
```

- `name` — מה שכתוב במסך הניצחון
- `icon` — אמוג'י שמופיע לידו
- `img` — הנתיב לקובץ, בדיוק כמו שקראת לו

זה הכל. אין הגבלה על הכמות.

## להחליף ממתק קיים

שים קובץ חדש באותו שם, או שנה את `img` בשורה שלו.

## להוריד ממתק

מחק את השורה שלו מ-`CANDIES`. את הקובץ אפשר להשאיר או למחוק.

## מה עושה תמונה טובה כאן

הלוח חושף את התמונה **משבצת-משבצת**, כל אחת בערך 30 פיקסלים. זה אומר:

- **המוצר צריך למלא את הפריים.** תמונה עם הרבה רקע מתגלה כרקע.
- **רוחב 800–1200 פיקסלים** מספיק. יותר גדול רק מאט את הטעינה.
- **צבעים חזקים וניגודיות גבוהה** עובדים הכי טוב — הם מזוהים גם כשרק חלק מהלוח נפתח.
- **בלי טקסט קטן.** הוא לא ייקרא.
- פורמט: `.jpg` או `.png`.

## אם קובץ חסר

המשחק לא נשבר — הוא מזהה שהתמונה לא נטענה, מגריל ממתק אחר, ורושם אזהרה בקונסול.
